SmartCore nRF52840 Documentation
================================

Hardware reference and developer guide for the SmartCore nRF52840 STICK boards,
based on the EBYTE E73-2G4M08S1C module.

Two hardware revisions, **STICK V1** and **STICK V2**, are documented separately
where their circuitry differs. Software examples may require revision-specific
pin configuration.
