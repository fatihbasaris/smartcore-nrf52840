STICK V2
========

The V2 schematic includes an EBYTE E73-2G4M08S1C module, an MCP73831-based
battery charging circuit, Mini USB, an LM1117MP-3.3 regulator, SWD connections,
user LEDs, a button, and expansion connectors.

The P1.06 LED blink test was reported as successful; the exact hardware
revision used for that test should be confirmed before assigning it here.

The original schematic PDF should be added here after final review.
