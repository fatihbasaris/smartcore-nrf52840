Getting Started
===============

The board has been programmed using Visual Studio Code, nRF Connect SDK,
SEGGER J-Link, and SWD. The ``nrf52840dk/nrf52840`` build target was used
for an initial LED blink test on **P1.06**. This validates basic programming
and GPIO operation, not complete board compatibility with the Nordic DK.

Detailed reproducible instructions and the exact application source will be
added after verification.
